# A股复盘：科技情绪线与资金流向分析

A股每日收盘复盘与市场情绪监测工具，聚焦科技主线、情绪周期与资金流向，输出结构化复盘报告与每日情绪指数（0-100）。

## 功能

- **每日 A 股复盘**：指数/量能/涨跌家数总览，科技线（AI应用、算力硬件、半导体等）主线强弱，情绪线（涨停/跌停/连板/封板率），资金流向，外围影响传导
- **情绪指数**：8 大情绪指标加权计算，输出 0-100 情绪指数与 6 档判断（极度冰点→过热/高潮），自动触发冰点/过热/结构/量能预警
- **历史冰点校准**：内置 2015 股灾、2016 熔断、2018 贸易战底、2020 疫情、2022 封控、2024 小微盘崩塌等 7 个历史冰点样本，公式已通过校准验证

## 快速使用

```bash
# 使用内置示例数据计算情绪指数
python scripts/emotion_index.py

# 自定义当日数据
python scripts/emotion_index.py --json ./today.json
```

JSON 输入字段：`date / z(涨停) / d(跌停) / h(最高板) / r(封板率0-1) / y(昨涨停今表现%) / b(涨跌家数比) / v(量能比) / m(两融月环比%)`

## 情绪指数公式

```
情绪指数 = Σ (权重 × 归一化得分) × 100
```

| 指标 | 权重 |
|---|---|
| 涨停家数 | 20% |
| 跌停家数（反向） | 15% |
| 连板空间高度 | 15% |
| 封板率 | 10% |
| 昨日涨停今表现 | 10% |
| 涨跌家数比 | 10% |
| 量能比 | 10% |
| 两融月环比 | 10% |

档位：0-20 极度冰点 / 20-40 冰点 / 40-55 中性偏弱 / 55-70 回暖 / 70-85 活跃偏热 / 85-100 过热。
